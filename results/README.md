# Results

One CSV per machine / lens / source / material combination. Copy
[`TEMPLATE.csv`](TEMPLATE.csv), rename it along the lines of
`lumos-ultra_f160_mopa_brass_leegillie.csv`, fill it in, and open a pull
request. An issue using the
[defocus ladder template](../.github/ISSUE_TEMPLATE/defocus-ladder.yml) is just
as welcome if you would rather not use git.

Raw widths only. No conclusions, no averaging, no cleaning -- the analysis
belongs in the protocol, where it can be argued with.
